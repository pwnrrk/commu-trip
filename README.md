# CommuTrip

Aim to be the community driven trip discover and management platform

## Goals

1.  Traveler discovery - Find information about the trip from chilling camp to hard trek. Posting shared budget trip or Tour provider with profit.
2.  Trip provider management - Manage trips event, accept bookings, aim to manage mass trip event like national park open trekking season or community managed area.
3.  Driver hubs, record and manage drivers for efficient cost and availability.

## Tech & Tools
- Next.js
- Nest.js
- Postgresql -> Trip and booking management.
- Mongodb -> Users, master information management.
- Chakra UI
- TailwindCSS
